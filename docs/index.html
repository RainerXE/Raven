Raven · v0.1

A GUI library for editors and tools.

Lightweight, multithreaded, written in C11 with no dependency. Write the interface and its code in one file, in C, C++, Rust, Python, Go, C#, Zig or Lua, and build it with the official IDE.

How it works

A window in a few lines.

Describe the interface in C, in XML, or both. Raven handles windows, layout, painting and the GPU.

1 · Initialize

Rinit(R_BACKEND_VULKAN). Raven opens its own windows and loads Vulkan at run time: nothing to link.

2 · Describe

Build the tree with the C API, write it in XML, or mix both. Every object is a Rid, checked on every call.

3 · Run your loop

One frame per call. A game never waits: while (Rdraw_frame()). A tool sleeps until something changes: while (Rwait_frame(-1.0)).

#include <Raven.h>

static void on_clicked(Rid button, void* user) { Rquit(0); }

int main(void) {
    Rinit(R_BACKEND_VULKAN);
    Rid window = Rwindow_create("Hello", 420, 220, R_WINDOW_DEFAULT);
    Rid box = Rwidget_create(R_WIDGET_VBOX);
    Rwindow_set_content(window, box);

    Rwidget_add_child(box, Rlabel_create("Hello from Raven"));
    Rid quit = Rwidget_add_child(box, Rbutton_create("Quit"));
    Rbutton_set_clicked_callback(quit, on_clicked, NULL);

    while (Rwait_frame(-1.0)) {}
    Rshutdown();
}

New · XMLC

One file. Interface and code.
In your language.

Write the window in XML and its code in <script> beside it. ravenc compiles the XML into your language: your compiler checks every callback and every widget, your usual tools build it, and no XML is read at run time.

<!-- src/main.xmlrs: a whole Rust program -->
<script>
use raven::*;
use std::sync::atomic::{AtomicI32, Ordering};
static CLICKS: AtomicI32 = AtomicI32::new(0);

// OnClicked="{on_hello}" below: checked by rustc
fn on_hello(_sender: Rid, _action: &str) {
    let n = CLICKS.fetch_add(1, Ordering::SeqCst) + 1;
    let text = cstr(&format!("{} clicks", n));
    // ui().status: the widget Name="status"
    unsafe { Rlabel_set_text(ui().status, text.as_ptr()) };
}

fn main() {
    unsafe { Rinit(R_BACKEND_VULKAN) };
    main_create();
    unsafe { while Rdraw_frame() != 0 {} Rshutdown() };
}
</script>
<Window Title="Hello" Width="400" Height="200">
  <VBox Spacing="12" Slot.Padding="24">
    <Label Name="status">Not clicked yet</Label>
    <Button Text="Click me" OnClicked="{on_hello}"/>
  </VBox>
</Window>

Your compiler checks it

OnClicked="{on_hello}" calls a function of your scripts and ui().status is the widget named status. A typo is a compile error, not a silent button.

Errors at their line

The scripts keep their line numbers (#line in C and C++). rustc says main.xmlrs:12, and the IDE opens it there.

Plain code, no glue

Any header, crate or package, no XML escaping, no generated header. Plain .xml stays interpreted with live reload while you design.

# C and C++: CMake
add_executable(hello main.xmlc)
target_link_libraries(hello PRIVATE raven::raven)
raven_target_xmlc(hello)

// Rust: build.rs
fn main() { raven_build::compile("src/main.xmlrs"); }

New project, eight languages

C, C++, Rust, Python, Go, C#, Zig or Lua: the main.xml…, the files of the language's own tools (CMakeLists.txt, Cargo.toml, go.mod, .csproj, build.zig) and the translations.

Visual and code, in step

Widgets, tree, live preview, properties and XML show the same document; each <script> opens in a tab of its language. Saving keeps your comments and your layout.

Completion of Raven

The whole API read from the headers, the widgets of the interface (ui.<Name>) and the keys of Rtr("…") while you type.

Build with the real tools

CMake, Cargo, go, dotnet, zig, Python, LuaJIT, with the environment set from the Raven package. Errors of GCC, Clang, MSVC, rustc and Go land on the line of your .xml….

Translations as a table

The CSV files of the project as a grid, one column per language. The preview switches language, right to left included.

Made with Raven

Docking, header bar, text editors, tree views: the IDE uses the public API only. What it does, your tools can do.

Rust · .xmlrs · Bevy

Raven Bevy Editor

A visual editor of 3D scenes for Bevy. Its whole interface, and all the code behind it, is one file: editor.xmlrs, about 1,450 lines of Raven XML and Rust, compiled by ravenc when Cargo builds.

  • Hierarchy, inspector, add panel, console, docked panels
  • Gizmos to move, rotate and scale, with snapping
  • Orbit camera, picking, undo of every gesture, scene files
  • Bevy renders the scene into the Raven viewport; a software renderer runs without it

Get started

Build it, link it.

CMake 3.16+ and a C11 compiler. On Linux, the X11 development package (libx11-dev). The Vulkan headers are downloaded when no SDK is found.

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
cd build && ctest -C Release --output-on-failure
add_subdirectory(raven)
target_link_libraries(app PRIVATE raven::raven)

Status

Version 0.1, honestly.

Raven was developed on one Linux machine without a GPU. Here is what was checked, and what was not.

Verified

  • Layout, widgets, XML, text editor, docking, themes, animations, live reload: 12 headless test programs, about 20,800 checks.
  • Linux / X11 with real pointer and keyboard events.
  • C++, Python, Rust and Go bindings, built and run by the tests.
  • XMLC in C, C++, Rust, Python, Go and Lua: compiled, built by each tool and run; compiler errors land on the right line.
  • The Bevy Editor's interface, driven by a headless test (click, gizmo drag, undo, inspector, save and open).

Partly

  • Vulkan renderer and glass: pixel tests and examples on a software driver, never on a real GPU.
  • Run the examples in a Debug build (validation layers) before trusting it.
  • raven_web: tested on Linux with Chromium only.

Not yet

  • Windows: written against the headers, never linked or run.
  • macOS/Cocoa backend is implemented but has not yet been built or run on a Mac; native Wayland is not implemented.
  • C# and Zig bindings and their XMLC: generated, never compiled.
  • The Bevy renderer of the Bevy Editor: written for Bevy 0.16, not yet compiled.
