What's free

What you make with Raven is yours.

License or not, you can do whatever you want with the software you build with Raven: sell it, ship it to your clients, keep its source closed, use it at work. No royalties, no revenue share, no permission to ask. The only thing the license changes is the watermark — and a watermark on a tool you're proud of would be a shame.

Free edition

The default build. Every feature, every widget, every platform. Each window shows a small note in its bottom right corner, which never takes the mouse.

Release edition

The same library, built with -DRAVEN_EDITION=Release. No watermark. That's the only difference: not one feature is held back.

Your software

Commercial or not, open or closed, for one user or a million: it's yours in both editions. The license is about the watermark, not about what you're allowed to build.

After buying

Build the Release edition.

The Release edition is the same code without the watermark. Build it with one option:

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DRAVEN_EDITION=Release
cmake --build build --config Release
:: Windows
generate-cmake.bat --edition release
build.bat --edition release
dist.bat --edition release

Questions

FAQ.

Can I sell software made with the free edition?

Yes. Whatever you make with Raven is yours, with or without a license: you can sell it, ship it, close its source. The free edition only shows the watermark.

What exactly does the license change?

Only the watermark. The free and the Release editions have the same features, the same performance and the same platforms.

Which license do I need?

If you are one person (freelance, indie, student, hobbyist), the personal license: $20, once. If Raven is used inside a company, the company license: $200 per month, for all its developers.

Does the watermark get in the way?

It's a small note in the bottom right corner of each window. It never takes the mouse: what is under it still gets the clicks. But it's there, on every window.

Can I cancel the company license?

Yes, at any time. The subscription is handled by Stripe.
